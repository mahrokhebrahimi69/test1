# شروع سریع نیروی جدید QA — مسیر مطالعه

## هدف این صفحه
در ۵ روز اول بفهمی تپسی‌فود چیست، اسکوادها چه می‌کنند، کجا تست کنی، و چه چیزی را هنوز نباید دانسته فرض کنی.

---

## روز ۱ — تصویر بزرگ

1. صفحه Home انبوردینگ
2. صفحه «تپسی‌فود چیست؟»
3. واژه‌نامه (حداقل Carousel, Tile, Availability, OMS, Own Delivery, Zap, OTP)
4. از tapsi.food به‌عنوان کاربر واقعی استفاده کن و مسیر زیر را طی کن:
   - باز کردن هوم
   - دادن آدرس
   - سرچ رستوران
   - ورود به منو
   - افزودن به سبد

**خروجی روز ۱:**  
یک پاراگراف بنویس: «تپسی‌فود از نظر من چه مسیری را برای سفارش طی می‌کند؟»

---

## روز ۲ — اسکوادها و مرزها

1. صفحه نقشه اسکوادها را کامل بخوان
2. برای هر اسکواد یک خط بنویس: «اگر باگ X دیدم، اول سراغ این اسکواد می‌روم»
3. وضعیت Gaps را بخوان؛ بدان کجاها دانش ناقص است

**خروجی روز ۲:**  
جدول شخصی اسکواد → مثال باگ → Owner احتمالی

---

## روز ۳ — Platform

به ترتیب بخوان و Smoke ذهنی بکش:

1. Icarus (SSO/Login)
2. Artemis (Profile/Address)
3. Iris (Notification)
4. Yggdrasil (Category/Tag)
5. Athona (Rate & Review)
6. مرور سریع Atlas / Melia / Saga / BiFrost (فقط بدانند وجود دارند)

**خروجی روز ۳:**  
نمودار وابستگی روی کاغذ/میرو از Login تا Review

---

## روز ۴ — ابزارها و دسترسی‌ها

1. صفحه لینک‌ها را باز کن
2. برای هر سامانه وضعیت دسترسی‌ات را تیک بزن
3. وارد شو:
   - BO Stage
   - Chef Stage
   - Kibana Stage
   - Metabase
   - Order Dashboard (اگر دسترسی داری)
4. یک Trace نمونه در Kibana برای Icarus پیدا کن

**خروجی روز ۴:**  
لیست دسترسی‌های Blocked برای Team Lead

---

## روز ۵ — اولین تست واقعی

با کمک Senior QA یک Happy Path در Stage اجرا کن:

```text
Login → Set Address → Discover Vendor (SD) → Add to Cart (COMP) →
Apply Coupon (PROMC) → Place Order path (OMS405) →
Check delivery state (DEL) → Check notification (Iris) → (optional) Review (Athona)
```

**خروجی روز ۵:**  
گزارش کوتاه:
- چه چیزهایی پاس شد
- کجا گیر کردی
- کدام Gap مانع شد

---

## ما چه کار می‌کنیم؟ (خلاصه برای نیروی جدید)

ما QA تپسی‌فود هستیم. تپسی‌فود یک فوددلیوری است که با چند اسکواد جدا توسعه داده می‌شود.

کار ما فقط «کلیک روی سایت» نیست. باید بفهمیم:

- کدام اسکواد Owner رفتار است
- کدام سرویس Platform درگیر است
- اثر جانبی روی پرداخت، ارسال، نوتیف، ریویو چیست
- چطور با Kibana/Metabase/پنل‌ها شواهد جمع کنیم
