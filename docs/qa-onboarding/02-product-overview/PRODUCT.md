# تپسی‌فود چیست؟

## خلاصه یک‌خطی

**تپسی‌فود (tapsi.food)** یک پلتفرم **فود دلیوری** است: کاربر رستوران و غذا را پیدا می‌کند، سفارش می‌دهد، پرداخت می‌کند، و سفارش با ارسال رستوران یا ناوگان زپ (Zap) به دستش می‌رسد.

---

## بازیگران اصلی

| بازیگر | نقش |
| --- | --- |
| مشتری (Customer) | جستجو، سفارش، پرداخت، پیگیری، ریویو |
| رستوران / وندور (Vendor) | مدیریت منو، دریافت سفارش، آماده‌سازی، گاهی ارسال |
| پیک / زپ (Zap) | ارسال سفارش‌هایی که دلیوری تپسی‌فود انجام می‌دهد |
| همکاران ستادی (Chef) | عملیات داخلی و ارتباط با رستوران‌ها |
| Support / Moderation | مدیریت کامنت، ریویو، پشتیبانی |
| بیزنس / مارکتینگ | پروموشن، کوپن، پیج‌بیلدر، کمپین |

---

## سفر کاربر (User Journey) — نسخه QA

### ۱) قبل از درگاه / قبل از سفارش

1. ورود / ثبت‌نام (سرویس Auth: **Icarus**)
2. پروفایل و آدرس کاربر (**Artemis**)
3. انتخاب آدرس → تصمیم دسترسی‌پذیری: کدام رستوران/غذا در این آدرس نشان داده شود (**Search & Discovery / Availability**)
4. سرچ رستوران و غذا
5. مشاهده هوم‌پیج / کروسل / تایل / دسته‌بندی‌ها
6. ورود به صفحه رستوران و منو (**MM**)
7. افزودن به سبد (**COMP**)

### ۲) سفارش و پرداخت

1. ثبت سفارش (**OMS**)
2. اعمال کوپن / پروموشن (**PROMC**)
3. پرداخت از درگاه (**Finance**)
4. نوتیفیکیشن وضعیت (**Iris**)

### ۳) ارسال

1. تعیین مدل ارسال:
   - ارسال توسط رستوران (Own Delivery)
   - ارسال توسط تپسی‌فود / زپ (OFOOD / Zap)
   - پیکاپ (Pickup)
2. پیگیری وضعیت دلیوری (**Delivery**)

### ۴) بعد از سفارش

1. ثبت امتیاز و نظر (**Athona** / Rate & Review)
2. مودریشن کامنت در صورت نیاز (**AI / Support**)
3. به‌روزرسانی ریتینگ وندور/محصول

## مدل کسب‌وکار به زبان ساده

تپسی‌فود واسطه بین مشتری و رستوران است:

- به مشتری کمک می‌کند سریع‌تر غذا پیدا و سفارش دهد
- به رستوران سفارش، پنل مدیریت و (در برخی مدل‌ها) ارسال می‌دهد
- با پروموشن و کوپن تقاضا را تحریک می‌کند
- با امتیاز/کامنت کیفیت را شفاف می‌کند

## نکته مهم برای QA

تپسی‌فود یک اپ monolith نیست؛ مجموعه‌ای از **اسکوادها + میکروسرویس‌ها** است.

برای هر باگ یا تست باید بپرسید:

1. این رفتار مال کدام اسکواد است؟
2. کدام سرویس Owner است؟
3. اثر جانبی روی کدام سرویس‌های دیگر دارد؟
4. در کدام محیط (Dev / Stage / Prod) باید چک شود؟
