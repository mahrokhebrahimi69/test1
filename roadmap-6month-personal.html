مفاهیم کلیدی — توضیح ساده

Git — دفترچه تغییرات تیم

هر تغییر کد = commit. هر feature = branch. PR = درخواست merge.

git add نام-فایل git commit -m "اضافه کردن تست لاگین" git push
Docker — جعبه آماده اجرا

برنامه + همه dependencyها در یک container. روی لپتاپ و سرور یکسان اجرا می‌شود.

Backward Compatible — تغییر جدید، قدیمی را نشکند

API نسخه ۲ فیلد جدید اضافه می‌کند ولی فیلد قدیمی را حذف نمی‌کند. اپ قدیمی هنوز کار می‌کند.

سوال در جلسه: «این تغییر backward compatible هست؟»

Consumer / Producer

Producer پیام می‌فرستد → [صف پیام] → Consumer پیام را می‌گیرد و واکنش نشان می‌دهد.

سوالات تست: اگر پیام دوبار برسد؟ اگر consumer خاموش باشد؟

Race Condition

دو عملیات همزمان روی یک منبع → نتیجه غلط. مثال: دو نفر همزمان یک صندلی رزرو کنند و هر دو موفق شوند.
